## Setup & Deploy Guide

### Step 1 — Fork / Clone Repository

```bash
git clone https://github.com/M-M-MALIKxMD/marco-malik_md.git
cd marco-malik_md
```

### Step 2 — Install Dependencies

```bash
npm install --legacy-peer-deps
```

### Step 3 — Configure Environment

```bash
cp .env.example .env
```

Edit `.env` file:

```env
SESSION_ID=MARCO_MALIK_&_SYED-MD~
BOT_NAME=Marco Malik MD Bot
OWNER_NAME=Marco Malik
OWNER_NUMBER=923001234567
PREFIX=.
MODE=public
OPENAI_API_KEY=sk-your-openai-key
ANTI_CALL=true
AUTO_REACT=true
AUTO_STATUS_READ=true
ANTI_DELETE=true
```

### Step 4 — Get Section ID (Pairing)

1. Click **Get Section ID** button above
2. Enter your WhatsApp number
3. Get 8-digit pairing code
4. On your phone: **WhatsApp → Settings → Linked Devices → Link with phone number**
5. Enter the pairing code

### Step 5 — Run Locally

```bash
node index.js
```

### Step 6 — Deploy on Railway

[![Deploy on Railway](https://img.shields.io/badge/One%20Click%20Deploy-Railway-8B00FF?style=for-the-badge&logo=railway&logoColor=white)](https://railway.app/new/template?template=https://github.com/M-M-MALIKxMD/marco-malik_md)

1. Click **Deploy on Railway** button above
2. Connect your GitHub account
3. Add Environment Variables from `.env.example`
4. Add `SESSION_ID=MARCO_MALIK_&_SYED-MD~` in Variables
5. Deploy — Bot goes live!

**Add Volume for permanent session:**
- Railway → **+ New → Volume**
- Mount Path: `/app/auth_info`

### Step 7 — Deploy on Heroku

[![Deploy on Heroku](https://img.shields.io/badge/One%20Click%20Deploy-Heroku-430098?style=for-the-badge&logo=heroku&logoColor=white)](https://heroku.com/deploy?template=https://github.com/M-M-MALIKxMD/marco-malik_md)

## Important Notes

| Feature | Detail |
|---------|--------|
| Session | After pairing, session saved in `auth_info/` |
| Railway | Add Volume at `/app/auth_info` for permanent session |
| AI | Set `OPENAI_API_KEY` for `.ai` `.gpt` `.imagine` commands |
| Songs | Max 10 minutes duration |
| Videos | Max 5 minutes duration |
| Anti-Call | Auto-rejects incoming calls |
| Auto-Reconnect | Bot reconnects automatically on crash |
